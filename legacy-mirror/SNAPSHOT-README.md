# Legacy-Mirror der Schul-Website

Snapshot von https://www.grundschule-paul-klee.de/ erzeugt am 2026-04-27 mittels `wget --mirror`.

## Zweck
- Inhaltsbasis fuer Migration auf moderne Architektur
- Vergleichsreferenz beim Aufbau der neuen Foerderverein-Website
- Archiv des Status-quo

## Wichtige Hinweise
- Dieser Snapshot dient ausschliesslich internen Zwecken (Analyse, Migration).
- Die Inhalte (Texte, Bilder, Logos) unterliegen dem Urheberrecht der Schule bzw. Dritter.
- Der Snapshot darf NICHT 1:1 unter neuer Domain veroeffentlicht werden, ohne dass die Rechte geklaert sind.
- Vor Live-Schaltung jeder uebernommenen Inhalte: Pruefung auf Aktualitaet, Datenschutz (DSGVO) und Rechte.

## Technische Details
- Tool: wget --mirror --convert-links --adjust-extension --page-requisites
- Dateien: ~230
- Groesse: ~85 MB
